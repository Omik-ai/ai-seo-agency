# Code of Conduct

## Our Pledge

In the interest of fostering an open and welcoming environment, we as contributors and maintainers pledge to make participation in our project and our community a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

### Positive Behavior

- **Be respectful** — Treat all individuals with respect and dignity
- **Be inclusive** — Welcome newcomers and diverse perspectives
- **Be constructive** — Provide helpful feedback and contributions
- **Be patient** — Remember that others may have different levels of experience
- **Be collaborative** — Work together to achieve common goals

### Unacceptable Behavior

- **Harassment** — Any form of harassment is not tolerated
- **Discrimination** — Discrimination based on any protected characteristic
- **Personal attacks** — Attacking or insulting others
- **Trolling** — Deliberately provoking inflammatory responses
- **Spam** — Unsolicited promotional content
- **Doxing** — Sharing private information about others

## Our Responsibilities

### Maintainers are expected to:

- **Enforce this code** — Apply this code fairly and consistently
- **Remove harmful content** — Remove comments, code, or issues that violate this code
- **Ban repeat offenders** — Temporarily or permanently ban individuals who violate this code

### Contributors are expected to:

- **Follow the code** — Adhere to this code in all interactions
- **Report violations** — Report any violations to maintainers
- **Cooperate** — Work with maintainers to resolve any issues

## Scope

This Code of Conduct applies to:

- All project spaces (GitHub, discussions, etc.)
- All community interactions
- All contributions to the project

## Enforcement

### Reporting

If you experience or witness any violation of this code:

1. **Contact maintainers** — Reach out through GitHub or the project contact
2. **Be specific** — Provide details about the incident
3. **Maintain confidentiality** — Don't share details publicly

### Enforcement Process

1. **Review** — Maintainers review the report
2. **Investigate** — Gather additional information if needed
3. **Respond** — Take appropriate action
4. **Follow up** — Ensure the issue is resolved

### Consequences

Depending on severity, consequences may include:

- Verbal warning
- Private warning
- Temporary suspension
- Permanent ban
