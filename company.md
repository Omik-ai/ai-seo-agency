# Omik AI

**Omik AI** builds open, file-based tooling that turns your favorite AI coding assistants into production-grade workflows—starting with [AI SEO Agency](https://github.com/Omik-ai/ai-seo-agency), a multi-agent SEO orchestration system for Claude Code, Cursor, GitHub Copilot, and other CLIs.

## What we do

- **Practical agent systems** — Specialized agents, clear handoffs, and workflows you can run locally without a proprietary control plane.
- **SEO & growth engineering** — Audits, keyword and content work, technical SEO, analytics, and link-building patterns shipped as files and playbooks.
- **Tool-agnostic by design** — The intelligence lives in the repo, not a closed API.

## GitHub organization profile

To show a landing page on [github.com/Omik-ai](https://github.com/Omik-ai), use GitHub’s [custom organization profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile): create a **public** repository named `.github` in the org and add `profile/README.md` at the repository root.

A ready-to-copy `profile/README.md` for that repository is maintained in this repo at [`omik-github-org-scaffold/profile/README.md`](omik-github-org-scaffold/profile/README.md); copy its contents (or the whole `profile` folder) into the `.github` repository and push.
