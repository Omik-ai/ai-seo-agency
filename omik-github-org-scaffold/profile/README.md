## About

**Omik AI** ships practical agent orchestration in the open—workflows, agents, and playbooks you run locally, without a proprietary control plane. Our main public project is [**AI SEO Agency**](https://github.com/Omik-ai/ai-seo-agency): a file-based, multi-agent SEO system for Claude Code, Cursor, GitHub Copilot, and other CLIs.

## What we build

- Multi-agent task flows with clear handoffs and resumable state
- SEO and growth: audits, content, technical SEO, analytics, link building
- Tool-agnostic: intelligence lives in the repository
