# Skill: Competitor Analysis

**Invokable by**: competitive-intel, seo-strategist, keyword-research, link-building
**Trigger**: Competitive research, strategy development, gap analysis

## Analysis Framework

### Step 1: Competitor Identification

**Direct Competitors** (same product/service):
- Named by client
- Found via search for primary keywords

**SERP Competitors** (rank for same keywords but different business):
- May not be business competitors
- Important for content strategy

**Aspirational Competitors** (where client wants to be):
- Larger players in the space
- Study their mature strategies

### Step 3: Keyword Overlap Analysis

```
              [Our Keywords]
                   |
        ┌──────────┼──────────┐
        |    Only   |  Shared  |
        |    Ours   |          |
        |          [Overlap]   |
        |    Only   |  Shared  |
        |   Theirs  |          |
        └──────────┼──────────┘
                   |
            [Their Keywords]

Focus Areas:
- Shared keywords where they outrank us → Optimize
- Their unique keywords → Evaluate opportunity
- Our unique keywords → Protect/strengthen
- Keywords neither ranks for → First mover opportunity
```

### Step 8: Strategy Reverse-Engineering

For each competitor, answer:
1. What is their primary SEO strategy? (content-led? technical? links?)
2. What content types are they investing in?
3. Where do they get their best links?
4. What keywords are they actively targeting?
5. What recent changes have they made?
6. Where are they vulnerable?
