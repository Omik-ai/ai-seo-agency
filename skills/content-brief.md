# Skill: Content Brief Generation

**Invokable by**: content-strategist, on-page-seo, seo-strategist
**Trigger**: New content piece approved for production

## Content Brief Template

```markdown
# Content Brief

## Overview
- **Title (working)**: [SEO-optimized title]
- **Primary Keyword**: [keyword] | Volume: [X] | KD: [Y]
- **Secondary Keywords**: [list with volume/KD]
- **Search Intent**: [informational / commercial / transactional]
- **Content Type**: [blog / guide / landing page / tool / comparison]
- **Target URL**: [planned URL slug]
- **Target Word Count**: [min-max range]
- **Priority**: [P1/P2/P3]
- **Due Date**: [date]

## Audience
- **Target Reader**: [persona description]
- **Knowledge Level**: [beginner / intermediate / expert]
- **Pain Point**: [what problem are they trying to solve]
- **Desired Outcome**: [what they want after reading]

## SERP Analysis

### SERP Features Present
- [ ] Featured Snippet (type: paragraph / list / table)
- [ ] People Also Ask
- [ ] Image Pack
- [ ] Video Results
- [ ] Knowledge Panel

### Content Gap (what top results miss)
- [gap 1]
- [gap 2]

## Outline

### H1: [Title]

### H2: [Section 1]
- Key points to cover:
  - [point]
  - [point]
- Keywords to include: [list]
- Suggested word count: [range]

### H2: [Section 2]
- Key points to cover:
  - [point]

- Suggested word count: [range]

  A: [answer]

## SEO Requirements
- **Title Tag**: [60 chars max, keyword near front]
- **Meta Description**: [155 chars max, include keyword + CTA]
- **H1**: [include primary keyword]
- **Internal Links**: Link to these pages:
  - [URL] with anchor text "[text]"
  - [URL] with anchor text "[text]"

## Featured Snippet Strategy
- **Target Format**: [paragraph / ordered list / unordered list / table]

## Success Metrics (at 90 days)
- Organic traffic: [target]
- Keyword rankings: [primary KW in top X]
- Engagement: [time on page, scroll depth]
- Conversions: [target]
```

## Brief Quality Checklist
- [ ] Primary keyword has search volume data
- [ ] Search intent is clearly defined
- [ ] Outline covers all major subtopics from SERP analysis
- [ ] Content gap identified vs. competing pages
- [ ] Word count is competitive with top-ranking pages
- [ ] Internal linking targets specified
- [ ] E-E-A-T requirements are actionable
- [ ] Featured snippet strategy included (if opportunity exists)
- [ ] CTA and conversion goal defined
- [ ] Success metrics are measurable
