# Skill: On-Page Optimization

**Invokable by**: on-page-seo, content-strategist, technical-seo, ecommerce-seo
**Trigger**: Page optimization, content optimization, on-page SEO review

## Optimization Checklist

### Title Tag
- [ ] Primary keyword included (preferably near beginning)
- [ ] Length: 50-60 characters
- [ ] Compelling and click-worthy
- [ ] Unique across the site
- [ ] Brand name included (at end, separated by |)
- [ ] No keyword stuffing

**Formula**: `[Primary Keyword]: [Value Proposition] | [Brand]`

### Meta Description
- [ ] Primary keyword included naturally
- [ ] Length: 150-155 characters
- [ ] Includes a call-to-action
- [ ] Compelling value proposition
- [ ] Unique across the site
- [ ] Matches search intent

**Formula**: `[What the page offers]. [Key benefit]. [CTA]. [Trust signal if space].`

### URL
- [ ] Contains primary keyword
- [ ] Short and descriptive (3-5 words)
- [ ] Lowercase, hyphens between words
- [ ] No parameters, IDs, or dates (unless necessary)
- [ ] Follows site hierarchy

### Heading Structure
- [ ] One H1 per page (includes primary keyword)
- [ ] H2s for main sections (include secondary keywords)
- [ ] H3s for subsections
- [ ] Logical hierarchy (no skipped levels)
- [ ] Headings describe content below them
- [ ] No keyword stuffing in headings

### Content Body
- [ ] Primary keyword in first 100 words
- [ ] Semantic/NLP keywords distributed naturally
- [ ] Content matches search intent completely
- [ ] Content depth competitive with top-ranking pages
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bulleted/numbered lists where appropriate
- [ ] Tables for data comparison
- [ ] No keyword stuffing (natural reading)
- [ ] Reading level appropriate for audience

### Internal Links
- [ ] 3-5 contextual internal links per 1000 words
- [ ] Descriptive anchor text (not "click here")
- [ ] Links to related topic cluster pages
- [ ] Links to high-priority commercial pages where relevant
- [ ] Breadcrumb links present
- [ ] No broken internal links

### Images
- [ ] Descriptive file names (keyword-relevant)
- [ ] Alt text on all images (descriptive, keyword where natural)
- [ ] Appropriate file format (WebP/AVIF preferred)
- [ ] Compressed for speed
- [ ] Lazy loaded (below fold)
- [ ] Width/height attributes specified
- [ ] Responsive sizing

### E-E-A-T Signals
- [ ] Author byline with credentials
- [ ] Author page linked
- [ ] Sources and references cited
- [ ] Last updated date visible
- [ ] Expert quotes or data (where applicable)
- [ ] Trust badges/certifications (where applicable)

### Featured Snippet Optimization
For paragraph snippets:
- [ ] Answer the query concisely in 40-60 words
- [ ] Place directly after the H2 matching the query
- [ ] Start with "[Keyword] is..." or similar direct definition

For list snippets:
- [ ] Use ordered/unordered list HTML
- [ ] 5-8 items is ideal
- [ ] Each item concise but descriptive

For table snippets:
- [ ] Use proper `<table>` HTML
- [ ] Include header row
- [ ] 3-4 columns, 4-8 rows

### Schema Markup
- [ ] Appropriate schema type for page type
- [ ] All required properties filled
- [ ] Validates without errors
- [ ] Matches visible page content
