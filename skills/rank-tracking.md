# Skill: Rank Tracking & Analysis

**Invokable by**: analytics, keyword-research, seo-strategist, client-manager
**Trigger**: Position monitoring, ranking reports, movement analysis

## Tracking Setup

### Keywords to Track
- All primary target keywords (from keyword-research)
- Brand keywords
- Top traffic-driving keywords (from GSC)
- Competitor target keywords
- Local keywords (with geo-location)

### Tracking Parameters
- **Frequency**: Daily for top 50 keywords, weekly for the rest
- **Location**: Target market geographies
- **Device**: Desktop AND mobile (separate tracking)
- **Search Engine**: Google primary, Bing secondary

### Visibility Score
```
Visibility = Σ (CTR_at_position × search_volume) for all tracked keywords

Estimated CTR by position:
#1: 31.7%  #2: 24.7%  #3: 18.6%
```

### Cannibalization Detection
If multiple pages from the same site rank for one keyword:
| Keyword | Page 1 (URL + Position) | Page 2 (URL + Position) | Action |
|---------|------------------------|------------------------|--------|
| | | | Consolidate / Canonical / Differentiate |

## Alert Triggers
- Any P0 keyword drops more than 5 positions → immediate notification
- Overall visibility drops >10% week-over-week → investigation
- New competitor enters top 5 for core keywords → competitive alert
- Featured snippet lost → recovery action

## Reporting Cadence
- **Daily**: Automated position check, anomaly detection
- **Weekly**: Summary of movements, quick win identification
- **Monthly**: Full ranking report with visibility trends
- **Quarterly**: Strategic ranking review with goal assessment
