# Workflow: Deep Competitive Analysis

**Type**: Parallel Swarm → Debate/Adversarial
**Duration**: 3-5 days
**Agents**: competitive-intel (lead), keyword-research, content-strategist, link-building, technical-seo

## Overview

A comprehensive competitive analysis deploys multiple agents to analyze competitors from every angle, then uses an adversarial debate pattern to challenge findings and produce robust strategic recommendations.

## Pipeline

```
Phase 1: Parallel Intelligence Gathering
├── competitive-intel: Overall competitive landscape
├── keyword-research: Keyword overlap/gap analysis
├── content-strategist: Content strategy comparison
├── link-building: Link profile comparison
└── technical-seo: Technical capability comparison

Phase 2: Adversarial Review (Debate Pattern)
├── Agent A presents findings
├── Agent B challenges assumptions
├── Agent C synthesizes consensus
└── Repeat per major finding

Phase 3: Strategy Formulation
└── seo-strategist: Counter-strategy development
```

## Phase 1: Intelligence Gathering (Parallel Swarm)

### competitive-intel (Lead)
- Map the complete competitive landscape
- Profile each competitor's overall SEO strategy
- Identify market positioning and differentiation
- Track recent competitor moves and investments

### keyword-research
- Full keyword overlap analysis
- Keyword gap analysis (they rank, we don't)
- Keyword opportunity analysis (neither ranks well)
- SERP feature ownership comparison

### content-strategist
- Content volume and frequency comparison
- Content quality and depth comparison
- Topic coverage comparison
- Content format comparison (blogs vs guides vs tools)
- E-E-A-T signal comparison

### link-building
- Referring domain comparison
- Link velocity comparison
- Link quality comparison (average DA, relevance)
- Link source analysis (who links to them uniquely)

### technical-seo
- Site speed comparison
- Mobile experience comparison
- Schema markup comparison
- Site architecture comparison
- Indexing efficiency comparison

## Phase 2: Adversarial Review

After gathering, agents challenge each other's findings:

### Round 1: Threat Assessment
- competitive-intel presents top 3 competitive threats
- Other agents challenge: "Is this really a threat? What data supports this?"
- Consensus on validated threats

### Round 2: Opportunity Validation
- keyword-research presents top opportunities
- content-strategist challenges feasibility
- link-building challenges ability to compete
- Consensus on realistic opportunities

### Round 3: Strategy Stress-Test
- seo-strategist proposes counter-strategy
- All agents identify potential failure points
- Refined strategy emerges
