# Workflow: Link Building Campaign

**Type**: Hierarchical Delegation
**Duration**: 30-90 days per campaign
**Agents**: link-building (lead), competitive-intel, content-strategist, analytics

## Overview

A structured link building campaign coordinated by the link-building agent, who delegates specific sub-tasks to supporting agents.

## Pipeline

```
link-building (Campaign Lead)
├── competitive-intel: Competitor backlink analysis
├── content-strategist: Linkable asset creation briefs
├── analytics: Target page performance data
└── link-building: Prospecting, outreach, tracking
```

## Phase 1: Research & Planning

### Step 1.1 — Campaign Setup (link-building)
**Actions**:
- Define campaign target pages and keywords
- Set link acquisition targets (quantity, quality thresholds)
- Choose campaign tactics

### Step 1.2 — Competitive Link Analysis (competitive-intel)
**Delegated by link-building**
**Actions**:
- Pull competitor backlink profiles for target keywords
- Identify link intersection opportunities
- Find competitor-exclusive link sources
- Analyze link types competitors are acquiring
**Returns**: Competitive Link Report → link-building

### Step 1.3 — Performance Baseline (analytics)
**Delegated by link-building**
**Actions**:
- Current ranking positions for target pages
- Current referring domain count and trend
- Domain authority trajectory
- Traffic to target pages
**Returns**: Link Campaign Baseline → link-building

## Phase 2: Asset Preparation

### Step 2.1 — Linkable Asset Strategy (content-strategist)
**Delegated by link-building**
**Actions**:
- Identify linkable asset opportunities (data studies, tools, infographics)
- Create briefs for link-worthy content
- Suggest angles for digital PR
**Returns**: Linkable Asset Briefs → link-building

### Step 2.2 — Prospect List Building (link-building)
**Actions**:
- Build prospect lists from competitive analysis
- Research resource pages, blogs, news sites in niche
- Qualify prospects (DA, relevance, likelihood)
- Find contact information
- Score and tier prospects

## Phase 3: Execution

### Step 3.1 — Outreach (link-building)
**Actions**:
- Personalize outreach templates per prospect
- Execute outreach sequences (initial, follow-up 1, follow-up 2)
- Track responses and conversion rates
- Handle link placement negotiations
- Verify acquired links

## Phase 4: Measurement

### Step 4.1 — Campaign Reporting (analytics + link-building)
**Actions**:
- Track links acquired vs. target
- Measure ranking changes for target pages
- Calculate cost per link and campaign ROI
- Document successful tactics and outreach angles
- Feed learnings back to strategy
